1. Project Overview

Custom 29-point alarm panel replacing the original Aqualarm unit on your vessel. The panel monitors bilge pumps, high water, fire detection, engine alarms, electrical system faults, refrigeration, navigation, and security sensors. Each alarm channel drives a red indicator LED and has an illuminated backlight label. Three green LEDs indicate engine running, genset running, and panel power. MUTE and TEST are lighted panel-mount pushbuttons.

The design was done in EasyEDA Standard. PCB layout uses programmatic component placement (Python scripts operating on the EasyEDA JSON format) with EasyEDA's auto-router for trace routing.

6. Special Circuits

Standard NO Circuit (23 channels)

Each standard channel has 9 components: Q_odd (NPN input), Q_even (PNP LED driver), D_direct (input protection), D_other (flyback), and 5 resistors (R1 LED current-limit, R2 base bias, R3 pull-down, R4 collector/LED path, R5 emitter).

NC Circuit — AL8 (Dinghy Theft)

Alarm triggers when the loop opens (wire cut, connector pulled). Circuit inverts standard NO logic.

Comparator Circuits — AL24, AL28

AL24 (overcharging) and AL28 (battery temp) use a comparator-based threshold circuit with U5 (LM393) and U3 (78L05 regulator). Monitors analog voltage level against a reference.

9. Integration & Test

  1. Inspect SMT assembly (solder joints, component orientation)
  2. Hand-solder TH components (buzzer, connectors, button headers)
  3. Power-on test: apply +24V, verify U4 green LED (panel power), all orange backlights illuminate
  4. Channel test: short each AL input to ground, verify correct RED indicator lights
  5. MUTE test: press MUTE, verify buzzer silences, indicator remains lit
  6. TEST test: press TEST, verify all RED indicators light simultaneously
  7. NC channel test (AL8): verify LED lit with loop closed, LED off with loop open (inverted logic)
  8. Comparator test (AL24/AL28): verify threshold trip points
  9. Engine running test: apply 24V to M/E ignition input, verify U1 green LED
  10. Mount faceplate, install in panel location, wire connectors to ship's alarm bus

10. Lessons Learned

EasyEDA JSON Format

  • Components are LIB~ entries in the shape array, with #@$ delimited sub-elements
  • Coordinate system: 1 EE-unit = 0.254mm = 10mil; multiply mm by 3.937 and add board origin offset
  • Designator is at position 10 inside TEXT~P~ sub-elements, not in the header fields
  • All sub-element coordinates (PAD, TRACK, SOLIDREGION, CIRCLE, TEXT, SVGNODE) are absolute — moving a component requires shifting every sub-element

PCB Layout

  • Connectors should follow signal flow: LED → R → connector. Place each column's connectors one column LEFT so resistors sit between LEDs and connectors. Reduces vias.
  • Never script-move TH connectors: Through-hole pad formats differ from SMD. The full_move function left ghost pads at original positions. Let EasyEDA handle TH placement natively.
  • Resistor numbering: Verify R designator formulas against the schematic netlist before running any automated placement. Off-by-one errors in the mapping put components near wrong LEDs.
  • Layer assignment matters: 40 components were initially on the wrong layer (front instead of back). Correcting layers before routing reduced vias from 234 to 228.
