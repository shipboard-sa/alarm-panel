6. Installation Steps (after all parts arrive)

  1. Hand-solder TH components to main PCB: buzzer, CN1–CN9 (9×), H4/H5 headers (2×)
  2. Test print label strips on RTL49 film — verify opacity, font size, alignment
  3. Cut label strips to cutout dimensions
  4. Mount pushbuttons through faceplate holes (12mm)
  5. Insert label strips into faceplate cutouts (adhesive or friction fit)
  6. Assemble faceplate to main PCB with M3 standoffs
  7. Wire pushbuttons to H4/H5 headers
  8. Wire alarm channels to CN1–CN8 per register 06
  9. Wire mute/buzzer interface to CN9
  10. Apply +24V power, verify all 29 channels + mute/buzzer
