3. Detailed Analysis

Option A: FR-4 PCB as Faceplate RECOMMENDED

Design a second PCB in EasyEDA with no electrical function — just the faceplate geometry. Use the board outline for the 305 × 140 mm shape, drilled holes for LEDs/buttons/buzzer, and silkscreen for all text labels.

  • + Cheapest by far: $2–5 per board at JLCPCB (5-piece minimum), same vendor as the main PCB
  • + Precise alignment: designed in the same tool as the main PCB, coordinates match exactly
  • + Multiple solder mask colors available (black, white, blue, green, red) — black with white silkscreen looks professional
  • + You get 5 copies — spares for revisions or mistakes
  • + Can be ordered alongside the main PCB in the same JLCPCB shipment
  • − Silkscreen is one color only (white on black, or yellow on other colors)
  • − FR-4 is not as rigid or premium-looking as aluminum
  • − 1.0 mm can flex slightly; 1.6 mm is stiffer but thicker
How to design it: In EasyEDA, create a new PCB project. Draw the board outline at 305 × 140 mm. Place drill holes at every LED position (use 1.5–2.0 mm diameter for 0805 LEDs). Add silkscreen text for all labels. Add mounting holes at the corners. Export Gerber and order from JLCPCB as a standard PCB (no components, no assembly). Choose black solder mask + white silkscreen for best contrast and marine readability.

LED Window Options (FR-4 method)

ApproachProsCons
Drilled holes (1.5–2.0 mm) Simple; light passes through cleanly Bare hole looks unfinished; dust entry
Soldermask-removed windows (no copper) Translucent FR-4 diffuses light; flush surface Dim unless LED is bright; yellowish tint through bare FR-4
Drilled hole + light pipe / diffuser Clean look; even light distribution Extra BOM item; 71 light pipes to install

Recommendation: Simple drilled holes. The 0805 LEDs are surface-mount directly under the faceplate. A 1.5 mm drill hole lets light through cleanly. If the bare hole bothers you later, you can add clear epoxy dots or a clear overlay film.

Option B: Front Panel Express

Professional anodized aluminum panels with CNC-milled cutouts and engraved/painted text. Their free Front Panel Designer software generates an instant quote.

  • + Best appearance — anodized aluminum with multi-color engraving
  • + Tight tolerances, professional finish
  • − Most expensive option ($80–200+ for a panel this size with 71+ cutouts and 40+ text labels)
  • − Each cutout and text string adds cost individually
  • − 7-day fabrication + US shipping
  • − Design file is proprietary (.fpd format) — must use their software

File format: .fpd (their own tool) — download Front Panel Designer, lay out holes and text, get instant quote.

Option C: SendCutSend

Laser-cut aluminum with optional laser engraving. Upload DXF/SVG, get instant quote.

  • + Fast turnaround (2–4 days)
  • + Good accuracy (±0.005″ / ±0.13 mm)
  • + Accepts SVG/DXF/DWG — easy to produce
  • − Engraving is surface-only (no color fill) — less readable than silkscreen or painted engraving
  • − Moderate cost for a one-off

File format: .svg, .dxf, .dwg, or .ai

Option D: Ponoko

Similar to SendCutSend. Laser cutting + engraving on metals and acrylics. Interesting option: two-color acrylic (e.g., black over white) — laser engraves the top layer to reveal white text underneath, no paint needed.

  • + Two-color acrylic gives sharp, durable labels with no paint fill
  • − Starts at ~$50 minimum for one part
  • − Custom material surcharge ($150–500) if your desired finish isn't in their catalog

4. Recommendation

Go with Option A: FR-4 PCB faceplate from JLCPCB.

Reasons:
  1. Cost: ~$5–15 for 5 pieces vs. $80–200 for one aluminum panel
  2. Alignment: Designed in the same EasyEDA project — LED hole positions can be copied directly from the main PCB
  3. Speed: Order it alongside the main board, ships together
  4. Iteration: If labels need revision, you have 4 spare boards and a $5 re-order
  5. Appearance: Black FR-4 with white silkscreen is clean and readable — adequate for a panel inside the engine room

If you want a premium finish later (e.g., for the salon or nav station), Option B (Front Panel Express) is the upgrade path.

5. Next Steps (FR-4 Faceplate)

  1. Create a new EasyEDA PCB project for the faceplate (305 × 140 mm board outline)
  2. Place drill holes at every LED position — extract X/Y coordinates from the main PCB JSON
  3. Add drill holes for MUTE/TEST pushbuttons and buzzer sound holes
  4. Add mounting holes at corners (M3 = 3.2 mm drill)
  5. Add silkscreen text: 29 channel labels, 4 column headers, title, PWR
  6. Choose: black solder mask, white silkscreen, 1.6 mm thickness, HASL finish
  7. Export Gerber, order from JLCPCB (PCB only, no assembly)
